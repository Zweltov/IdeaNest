# Короткий промпт: обложки идей и статей

```
Обложки IdeaNest — публичный URL картинки в колонке БД:

Идеи (таблица ideas):  cover_url
Статьи (таблица articles): cover_url

(допустимы также image_url, banner_url, thumbnail_url)

Пример:
cover_url = https://images.unsplash.com/photo-xxxx?...

На карточках: верх ~половина — фото (или градиент, если URL пустой), снизу тёмный текст.
На странице идеи/статьи с cover_url — большой hero, заголовок белый на затемнении.

В Markdown статьи обложку НЕ пиши — только колонка cover_url.
В текст статьи свои картинки по-прежнему так: ![описание](url)
Картинку бери горизонтальную, ~16:9 или 3:2, без мелкого текста на фото.
```
